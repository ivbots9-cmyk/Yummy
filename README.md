# Yummyland — подарочные боксы с конфетами

Сайт одного продукта в трёх размерах: **Ruby Gift Box** — бордовая коробка с лотком из
**4, 8 или 12 запечатанных ячеек** и крышкой, внутри которой напечатаны надпись под повод
и **два полароида**. Покупатель выбирает размер, наполняет ячейки (готовым боксом или сам),
решает, чьи фото будут в крышке, добавляет ленту и открытку.

Никакой сборки: HTML + CSS + ES5-совместимый JS, шрифты и картинки лежат в репозитории.
`python3 -m http.server 8000` → http://localhost:8000.

| `cart.html` | Корзина: боксы с превью, рефиллы, промокод, итог |

## Конструктор — четыре шага вниз по странице

Как у Sugarfina: шаги идут друг за другом, человек просто скроллит. Сверху липкая полоска
шагов, она подсвечивается по мере прокрутки и переносит к нужному шагу по нажатию.
На широком экране справа липкое живое превью бокса; **на телефоне** превью сжимается
в липкую полоску под шагами (мини-лоток, «8 / 8 cups», цена) и раскрывается в полный бокс
по тапу. Так человек всегда видит, что собрал, и не листает вверх-вниз.

1. **Size** — три карточки в ряд: The Little Box (4 ячейки, Serves 1–2, $32.99),
   **The Signature Box (8, Serves 3–5, $54.99, бейдж «Most popular», выбран по умолчанию)**,
   The Grand Box (12, Serves 6–10, $79.99). При смене размера бокс сохраняет уже выбранное:
   готовый набор пересобирается под новый размер, ручной набор обрезается/дополняется.
2. **Candy** — сверху готовые боксы (одно нажатие заполняет все ячейки под текущий размер),
   ниже вся линейка с фильтрами по типу и по цвету. Тап по ячейке выбирает её, тап по конфете
   кладёт в неё (или в первую пустую).
3. **Lid & photos** — главная фишка:
   - **«Who's it for?»** — 8 поводов (по умолчанию Just Because). Повод задаёт надпись на крышке
     и то, какие **наши** фото мы положим, если клиент не загружает свои;
   - **как оформить крышку** — три карточки с живой картинкой именно этой крышки:
     **свои фото +$5.99** (самая большая карточка, бейдж «Most loved»), **наши фото под повод**
     (бесплатно), **без фото** (бесплатно). Выбор обязателен, но отказаться можно;
   - при «своих фото» — две загрузки, фото сразу появляются в превью; подписи под фото.
4. **Extras & checkout** — если своих фото нет, сверху мягкое напоминание с картинкой крышки
   и кнопкой «Add my photos». Лента **+$6.99** и открытка **+$4.99**: при включении превью
   переключается на вкладку **«How it arrives»** (закрытая коробка с лентой и открыткой с текстом).
   Дальше состав, итог и «в корзину». Пока что-то не готово (пустая ячейка, свои фото не загружены,
   открытка без текста) — кнопка неактивна и есть ссылка «Fix it» на нужный шаг.

**Чего намеренно нет:** веса, лишнего совка, доплат за вкус. Хочешь больше конфет — берёшь размер
больше. Лоток фиксированный, коробка должна закрываться ровно, поэтому допы только те, что не меняют начинку.

Ссылки прямо в конструктор: `index.html?collection=rainbow-row#builder`,
`index.html?occasion=wedding#builder`, `index.html?size=large#builder` (можно вместе).

| The Signature Box · 8 ячеек · Most popular | **$54.99** |
| The Grand Box · 12 ячеек | **$79.99** |

| Открытка с текстом | +$4.99 |
| Пакет-рефилл 1 lb | $14.99–16.99 |

Доставка бесплатная на всё. Цены и названия размеров — моё предложение, меняются в `YL.SIZES`.
Экономика в комментарии к `YL.SIZES` в `data.js`: ячейка ~6 oz ≈ $4 конфет по полочной цене,
коробка + лоток + печать ≈ $6–10. Допы — почти чистая маржа. Вес ячейки — `YL.CUP_OZ`,
размеры коробок (`dims`) — рабочие, сверить с реальными коробками.

## Каталог — `assets/js/data.js`

Всё редактируется там, в HTML ничего не зашито.

- **`YL.SIZES`** — три размера: ячейки, колонки лотка, цена, «на сколько человек», габариты, SKU. `YL.CUP_OZ` — вес ячейки.
- **`YL.CANDIES`** — 47 позиций, порядок = порядок на витрине:
  - **Albanese гамми** (13 + 11 одноцветных мишек) — ядро линейки, у всех реальные фото
    с Shopify CDN;
  - **Albanese кислые** (4);
  - **Albanese шоколад** (5) + Rainbow Bites — **фото ещё нет**, карточки рисуют конфету кодом;
  - **другие**: Swedish Fish, Sour Patch Kids, Jolly Rancher (ассорти + 5 цветов);
  - **леденцы**: Starlight Mints, Butterscotch, Root Beer Barrels, Cinnamon, Lemon Drops —
    фото тоже нет.

  У каждой позиции: `label` (надпись на наклейке ячейки), `types`, `colors`, `swatch`,
  `brand`, `about`, `img`, `nuts` (помечается «contains nuts»).
  > ⚠️ Шоколад Albanese и леденцы вписаны по памяти — сайт Albanese из этой среды был
  > недоступен. Перед запуском сверить SKU и названия с тем, что реально закупается,
  > и проставить `handle` и `img`.
- **`YL.OCCASIONS`** — 8 поводов: надпись, строка, подписи, цвета заглушки, иконка,
  рекомендованная коллекция.
- **`YL.COLLECTIONS`** — 10 готовых боксов, у каждого **12 id по важности**: первые 4 = Little,
  первые 8 = Signature, все 12 = Grand. Порядок же раскладывает цветовые истории по рядам:

  | Коллекция | Идея |
  |---|---|
  | The Signature Mix | лучшее из гамми Albanese |
  | The Bear Bar | только мишки |
  | Rainbow Row | по цвету на ячейку: красный → фиолетовый |
  | Ruby & Sapphire | верхний ряд красный, нижний синий |
  | Ruby Romance | все оттенки красного и розового |
  | Pearl & Blush | белое и пудровое — свадьба, baby shower |
  | The Sour Edit | кислое |
  | Chocolate Lounge | шоколад Albanese |
  | Gold & Ruby | половина гамми, половина шоколад |
  | The Candy Counter | леденцы в обёртке |
- **`YL.EXTRAS`** — три платных допа. **`YL.PRODUCTS`** — пакеты-рефиллы.
- `YL.FAQ`, `YL.HOW`, `YL.TRUST`, `YL.ANNOUNCE` — тексты.
- `YL.REVIEWS` — **заглушки**, на страницы сейчас не выводятся. Появятся реальные отзывы —
  вписать и вызвать `YL.renderReviews`.

## Картинки: что есть и что сгенерировать

Уже в репозитории (нарезаны из мокапов бокса):
`hero-box.webp/jpg` (герой), `box-open.webp` (бокс изнутри), `box-closed.webp`,
`box-wrapped.webp` (с лентой — картинка допа), `card.webp` (открытка), `box-insert.webp`
(вкладыш), `og.jpg` (превью ссылки), `lid/just-because-1/2.webp`.

**Нужно сгенерировать** — пока файла нет, на его месте аккуратная заглушка в цветах повода,
ничего не ломается:

| Файл | Что |
|---|---|
| `assets/img/lid/<повод>-1.webp`, `-2.webp` | по 2 фото на повод (квадрат ~600 px): `birthday`, `wedding`, `baby-shower`, `best-friend`, `love`, `thank-you`, `congrats` (для `just-because` уже есть) |
| `img` у 11 позиций без фото | шоколад Albanese, Rainbow Bites, 5 леденцов — фото россыпью |

Карточки коллекций рисуют бокс кодом из реальных шести ячеек, так что фото коллекций
не обязательны.

## Публикация

- **GitHub Pages** — `.github/workflows/pages.yml` (репозиторий public, Settings → Pages →
  Source: GitHub Actions). Workflow сам качает фото конфет и ставит хеши на css/js.
- **Netlify / Vercel** — конфиги в корне.
- После выбора домена: `SITE_URL=https://домен node tools/build-seo.js`.

Фото конфет: `node tools/fetch-photos.js` (скачать), `--check`, `--restore`.

## Перед запуском рекламы

1. Сгенерировать фото крышек по поводам и недостающие фото конфет (таблица выше).
2. Сверить шоколад и леденцы с реальной закупкой (см. ⚠️ выше).
3. Проверить `YL.CUP_OZ`, `dims` и цены трёх размеров на реальных коробках и лотках.
4. Отзывы — только настоящие.
5. Пиксели GA4 / Meta / TikTok в `<head>` — события уже летят (`analytics.js`).
6. Terms / Privacy — настоящие тексты (сейчас ссылки ведут на FAQ).
7. Приём денег — через Shopify (`shopify/README-SHOPIFY.md`); в статике чекаут симулируется.
