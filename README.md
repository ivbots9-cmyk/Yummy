# Yummyland Candy — конструктор боксов конфет

Статический сайт магазина Yummyland Candy с главной страницей-конструктором:
покупатель выбирает размер бокса, набирает конфеты, задаёт «вайб» и допы,
а превью бокса и цена пересчитываются вживую.

Собирается без сборщика и зависимостей: чистые HTML + CSS + ES5-совместимый JS.
Достаточно открыть `index.html` или отдать папку любому статик-хостингу
(GitHub Pages, Netlify, Vercel, S3).

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: герой + **конструктор бокса** (5 шагов), как это работает, популярные боксы, поводы, блок для офисов, отзывы, FAQ |
| `boxes.html` | Каталог готовых боксов + витрина всех конфет с фильтрами по категориям |
| `cart.html` | Корзина: позиции, количество, промокод, доставка, оформление (демо) |
| `about.html` | О компании, качество и состав, офисы/мероприятия, форма обратной связи |
| `faq.html` | FAQ, доставка, возвраты и гарантия |

## Конструктор

1. **Размер** — Small / Medium / Large / Party (4 / 7 / 10 / 15 слотов, $24.99–$69.99).
   При уменьшении размера лишние конфеты аккуратно срезаются.
2. **Конфеты** — 22 позиции с фильтрами (гамми, кислые, шоколад, орехи, freeze dried,
   классика, премиум). Премиум-позиции добавляют наценку к цене бокса.
3. **Вайб** — просто себе, подарок, день рождения, офис, киновечер, вечеринка,
   праздник, «удиви меня» (последний собирает случайный бокс сам).
4. **Допы** — открытка (бесплатно), стикеры, доп. порция конфет, конфета-сюрприз,
   премиум-упаковка, цвет бокса (5 цветов).
5. **Проверка** — сводка со ссылками «Edit» на нужный шаг и кнопка «в корзину».

Дополнительно:

- **Живое превью** справа — SVG-бокс перерисовывается под выбранные конфеты,
  наполненность и цвет; чипсы выбранных конфет с удалением в один клик.
- **Auto-build** — 5 готовых миксов (Sour Lover, Sweet & Fruity, Chocolate Lover,
  Party Mix, Random) заполняют бокс одной кнопкой.
- **Сохранение** — черновик бокса, сохранённые боксы и корзина живут в `localStorage`,
  так что вкладку можно закрыть и вернуться.
- **Готовые боксы** открываются в конструкторе через `index.html?box=<id>`
  (например `index.html?box=movie-night`) или добавляются в корзину сразу.
- Промокоды в корзине: `SWEET10` (−10%) и `YUMMY5` (−$5).
  Доставка $4.99, бесплатно от $50.

## Структура

```
index.html, boxes.html, cart.html, about.html, faq.html
assets/css/style.css      дизайн-система (цвета, кнопки, карточки, адаптив)
assets/js/art.js          вся графика: SVG-конфеты, бокс, иконки, логотип
assets/js/data.js         каталог: размеры, конфеты, вайбы, допы, готовые боксы, FAQ
assets/js/store.js        расчёт цены бокса, корзина и черновик в localStorage
assets/js/site.js         шапка, подвал, тосты
assets/js/pages.js        переиспользуемые секции (как это работает, боксы, отзывы, FAQ)
assets/js/builder.js      сам конструктор
assets/js/cart.js         страница корзины
```

## Про картинки

Фотографий продукта в проекте нет — вся графика (конфеты, коробки, иконки)
генерируется кодом в SVG (`assets/js/art.js`). Благодаря этому превью бокса
реагирует на выбор покупателя, ничего не весит и не требует CDN.
Когда появятся реальные фото, проще всего заменить вызовы `YL.candyTile()`
и `YL.boxArt()` на `<img>` — данные о конфетах уже лежат в `data.js`.

## Что дальше (не реализовано намеренно)

Оформление заказа симулируется на клиенте: оплаты, бэкенда и учёта остатков нет.
Для боевого запуска сюда подключается корзина/чекаут платформы
(Shopify Storefront API, Stripe Checkout и т.п.) — состав бокса уже сериализуется
в объект, который можно отправить как line item properties.

## Локальный запуск

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```
