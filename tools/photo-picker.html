Pick the bulk photo

Every photo Shopify holds for each candy, in order. Click the one that shows the loose candy rather than the retail packet — that is what belongs on a pick-and-mix card. The highlighted one is what the site uses today, so you only need to touch the ones that are wrong. When you are done press Export choices and save the result as tools/photo-choices.json, then run node tools/apply-photo-choices.js.
