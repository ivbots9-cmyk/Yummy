# Перенос конструктора на Shopify

Этот каталог — готовый «drop-in» для любой темы Shopify 2.0 (Dawn и её производные).
Конструктор встраивается секцией, корзина и оплата — родные шопифаевские.

Всё в `shopify/assets/` генерируется из исходников командой:

```bash
node tools/build-shopify.js
```

Правим всегда исходники в `assets/`, потом пересобираем. Руками в `shopify/assets/` не редактируем.

---

## Как это устроено

Shopify не умеет считать цену «сконструированного» товара на лету, поэтому используется
стандартная и надёжная схема:

| Что | Как попадает в корзину |
|---|---|
| Сам бокс | товар **Build Your Own Candy Box**, вариант = размер (Small/Medium/Large/Party) |
| Состав бокса, вайб, открытка | **line item properties** на этой позиции (видны в корзине, чеке и на упаковочном листе) |
| Платные допы (стикеры, упаковка…) | отдельные позиции-товары `yl-extra-*` |
| Наценка за премиум-конфеты | отдельные позиции-товары `yl-premium-*` |

Все позиции одного бокса помечаются скрытым свойством `_yl_group`, так что в админке видно,
что относится к одному боксу. Свойства с `_` в начале покупателю не показываются.

Полный состав бокса дополнительно кладётся в `_yl_payload` в JSON — удобно для приложений
печати упаковочных листов и для аналитики.

## Пошагово

### 1. Импорт товаров

1. Admin → **Products → Import** → загрузить `shopify/products.csv`.
   Создаётся 1 товар с 4 вариантами + 11 товаров-допов.
2. Создать коллекцию **Box add-ons** (handle `box-add-ons`), тип — automated,
   условие: `Product tag equals yl-addon`. Туда попадут все 11 допов.
3. Чтобы допы не мозолили глаза в каталоге: в остальных коллекциях добавить условие
   `Product tag is not equal to yl-addon`, а в теме исключить их из поиска
   (или поставить им статус «доступен только по прямой ссылке» через Sales channels).

Цены в CSV взяты из `assets/js/data.js` — если меняешь цены, меняй их там и пересобирай CSV,
тогда витрина и корзина не разъедутся.

### 2. Загрузка файлов темы

Admin → **Online Store → Themes → ⋯ → Edit code**:

- всё из `shopify/assets/` → в папку **Assets** темы
  (включая `.woff2` — их можно загрузить как обычные ассеты);
- `shopify/sections/yummyland-builder.liquid` и `yummyland-marketing.liquid` → в **Sections**;
- `shopify/templates/page.build-your-box.json` → в **Templates**.

Быстрее через Shopify CLI из корня темы:

```bash
shopify theme dev            # локальный превью
shopify theme push --only "assets/yummyland-*" --only "sections/yummyland-*" --only "templates/page.build-your-box.json"
```

### 3. Страница конструктора

1. Admin → **Pages → Add page**, заголовок «Build Your Box», handle `build-your-box`.
2. Справа в **Theme template** выбрать `build-your-box`.
3. Открыть страницу в редакторе тем → в секции **Yummyland box builder** выбрать:
   - **Box product** → Build Your Own Candy Box
   - **Add-ons collection** → Box add-ons
4. Сохранить. Готово — конструктор работает, «Add to cart» кладёт бокс в родную корзину.

Размеры сопоставляются с вариантами **по названию** (ищутся слова small / medium / large / party),
поэтому ID вручную вписывать не нужно. Если варианты названы иначе — они возьмутся по порядку.

### 4. Главная страница

Секции `Yummyland box builder` и `Yummyland marketing` доступны и на главной:
Customize → Add section → выбрать их. Хедер, футер, меню и корзина остаются темины.

## Что важно знать

- **CSS изолирован.** Все стили в `yummyland-style.css.liquid` заскоупены под `.yummyland`,
  тема не поедет. Обратная сторона: markup конструктора обязан лежать внутри `<div class="yummyland">` —
  в секциях это уже так.
- **Корзина.** `assets/js/shopify-cart.js` подменяет `YL.addToCart`. Если товар-доп не найден
  в коллекции, бокс всё равно добавится, но наценка не спишется — в консоли будет предупреждение
  со списком недостающих handle. Проверь это после импорта на тестовом заказе.
- **Промокоды и доставка** со статичной версии (`SWEET10`, бесплатно от $50) на Shopify не нужны —
  настраиваются в Discounts и Shipping. Блок доставки в превью показывает «Calculated at checkout».
- **Страницы `cart.html`, `about.html`, `faq.html`** в тему не переносятся: корзина у Shopify своя,
  а About/FAQ проще сделать обычными страницами и перенести текст из `assets/js/data.js` (`YL.FAQ`).
- **Аналитика.** После успешного добавления бросается событие `yummyland:added`
  с составом бокса в `detail.box` — можно повесить GA4/Meta Pixel.

## Альтернатива: оставить как есть

Если Shopify пока не нужен, сайт полностью самодостаточен: это статика без сборки.
`README.md` в корне описывает деплой на GitHub Pages / Netlify / Vercel (конфиги уже лежат).
Корзина в этом случае живёт в браузере, а оформление заказа — демонстрационное:
принимать деньги без платёжного провайдера нельзя.

Разумный промежуточный вариант — оставить лендинг на статике, а кнопку «Add to cart»
увести в Shopify через тот же адаптер (Storefront API + permalink `/cart/<variant>:<qty>`),
если хочется свой фронт и шопифаевский чекаут.
